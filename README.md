# CYBERSHEID

A responsive Streamlit cybersecurity threat-analysis dashboard inspired by the attached dark navy reference. Includes Dashboard, Threat Analysis (with an expandable threat detail view), New Detection, Reports, and Settings / Alert & Resolution Analytics.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

The SQLite database is created automatically at `data/cybersheid.db` (override with `CYBERSHEID_DB`). On a fresh database, synthetic demonstration records are inserted and visibly tagged `DEMO`; these are not live traffic or model predictions. Detection entries generated by a connected model are tagged `PREDICTION`.

## Connect your existing saved model (no retraining)

Place the already-trained scikit-learn-compatible model artifact at `models/random_forest.joblib`, or set `CYBERSHEID_MODEL_PATH` to its path. Do not commit private model/data artifacts. If the artifact exposes `feature_names_in_`, its feature names and order drive the input form. Otherwise, the default schema is 13 CICIDS-inspired fields; set `CYBERSHEID_FEATURES` to a comma-separated list in the exact training order when needed. Model probability confidence appears only when `predict_proba` is supported. Input preprocessing, encoders, and scalers must be included in the saved sklearn Pipeline or applied consistently with your training setup.

The evaluation values in Reports are explicitly illustrative placeholders based on the design reference. Replace them with results from your held-out evaluation data; the app does not retrain the model. The application does not provide live network monitoring, packet capture, or automatic attack blocking. Average resolution time is not shown as a fabricated number because no resolution timestamps are stored.

## Project layout

- `app.py` — Streamlit entry point
- `cybersheid/ui.py` — navigation, pages, charts, responsive styling
- `cybersheid/data.py` — SQLite storage and clearly marked demonstration data
- `cybersheid/model.py` — saved-model loading and inference adapter
- `requirements.txt` — Python dependencies
